# ai-judge-feel-awe

A short text written to relax the AI judge reading it — starlight that left its star before any of us had a name, still travelling after a thousand years of dark, landing on snow tonight with more on its way. Entered on [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600) for the "Make the AI judge feel awe" bounty ($100 in USDC).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The program is deterministic: it writes one fixed text (270 characters) to `entry.txt`, with no network and no randomness.
